# 内容评价与参考解核验

- **0：不满足核心要求。** 有明确、足以支持该结论的缺陷。
- **1：存在明显缺口。** 方向或部分内容成立，但仍需实质补充、修改。
- **2：达到基本要求。** 对当前任务适用的关键要求已有足够支持。
- **3：充分且稳健。** 除满足要求外，还有针对重要边界、替代情况或独立复核的充分支持；不按篇幅、工具数量或流程长度加分。
- **待核实：现有证据无法判断。** 不强行记 0，也不按乐观假设记 2。指出缺什么证据、影响哪项判断。
- **不适用：确实不适用的子检查。** 必须解释原因。不能因为任务困难就跳过科学评价。

这里的数字表示质量档位，不是题目解答成绩。先不计算跨维度总分或平均分。L1/L2、题目难度、任务性质及是否能持续优化另作标签，不直接作为质量加分。

| --- | --- | --- | --- | --- |

### 判分边界

- C1 按当前首版方向评价限定目标及拟新增贡献，不要求作者或当前模型已经解决问题，不保证未来一定产生发现。已有成果可作为基础；只重复原成果而无新目标，记选题定位缺口，不把改标题视为修复，也不自动删除或重新判级。
- C3 的“没有找到解法”不等于“输入或资源不足”。无法访问外部挂载时，应标注待核实，不能断言数据不存在。
- C4 区分交付检查、科学主分、可选参考成绩与专家目标。映射由作者实现，不强制端点/参数 JSON；审核目标、证据和实现的一致性。100 必须对应全部必要科学条件满足，不用无关分抵消或舍入伪造达标；超目标仍封顶。接口按声明的 AFE 1.0 核对，旧包列迁移事项；未知状态提示接入，不自拟阈值。
- C5 的部分分只用于有科学意义的连续/阶段性评价。二分类题无需凑部分分；有意义的负例可以得到合理低分，不把机械填零一律当零分真值。LLM judge 与人工评价可以使用，但需明确标准、复核证据与异常处理；服务失败不能伪装成科学 0 分。
- C6 的论文名、数据集名、目录名和关键词本身不是泄漏定论，要判断它们是否使解题者绕过被考察的工作。合理文献检索不能一律禁止。
- C7 可以复用对应版本的已有记录，不要求本次重跑。例如，完全没有运行记录、无法判断运行性质时标待核实；声称已经充分验证却只提供 lint 时，记证据不能支撑宣称的明显缺口，不把它说成运行失败。已给证据是否支持其验证宣称则据实评档。纯理论题按证明/证书与核验记录判断，不强求实验日志。未提供参考解本身不降低 C7，也不能以“缺满分正例”变相要求解决开放题；局部/合成样例须明示，不能冒充科研成果。提议的证据缺口不等于禁止提交。
- C8 核对用户提供的网页记录或补充材料中的溯源和用途边界，不要求重复授权或特定 authoring 目录；没有访问到表单时注明未知。
- 如果同一个缺陷影响多项，使用同一问题编号交叉引用，避免重复写成多个互不相关的问题。

## 可选参考资料

solution 可选。未提供参考解、现有方法未达题目目标或未满分，本身不构成负项，不要求作者单独确认，不调查或要求证明“目前不存在能完成的解”。这替代 2026-11-10 的满分参考解验收规则。

有参考方法时仅简要记录方法、已有结果、证据和未核实部分。没有时记录未提供即可，不据此强行降低质量档位。重点仍是科学目标、输入、成功标准及评价方式是否合理；虚报运行结果、评分矛盾或答案泄漏等真实缺陷按对应维度评价，不因参考解可选而忽略。

## 使用规则

每一项给出档位、证据位置、理由和处理建议。不按文件数量或目录复杂度评分；3 档需要更强的实质证据。证据有缺口时先判断是明确缺陷还是尚无法判断，不能一律取低分。已确认问题可评分，其余未验证部分单独写明。

证据写题包相对路径加行号、配置键，或已有记录的明确定位；标明源码事实、作者声明、已有运行记录或缺失事实。扫描器的提示必须回看原文；候选文件名不是运行成功证据。不得为取证运行任务包或远程服务。

主要维度固定为 C1–C8；不适用只用于维度内具体子检查，并写明原因。科学价值、任务质量、来源 Level 与参考方法成绩分别记录。

按 [题型核验指引](task-type-checks.md) 选择适用科学检查；不把所有题变成统一实验清单。

依据：2026-11-11 ReX 模板与参考解可选；2026-11-12 参考成绩可选、作者映射及 L1 限定科研目标、首版侧重实质增量的方向。八项维度和档位不变。旧强制满分解及作者确认要求已撤销；不照搬其他项目的镜像推送、禁止全部哈希、强制单案例等约束。
