# 按科研产物核验题包

适用：AFE L1“限定目标的科研挑战”。类别仅帮助选择检查重点，可以多选；不是新 Level，也不新增报告分数。未知解不等于不可验收。审核者判断的是题包的目标与评价设计，不代替执行研究或判定未见成果。

## 先核对共同链条

1. **贡献与目标（C1/C2）**：相对什么已有知识/能力，完成会新增什么，核对到什么时间？已知基础可以复用；纯重复既有成果而无实质新目标，记录首版选题定位缺口，不自动删题或升 L2。
2. **证据可获得（C3/C7）**：任务提供的条件能否支持所要求的判断？需要的材料与证据由谁产生、何时产生？没有读到外部材料标未知；没有满分解本身不扣分。
3. **实际验证（C4）**：从 test.sh 跟到核心判据。核验结果是否可信、材料是否足够判断、科学目标是否满足；每个必要条件能定位证据与判定方式。论文式写作、文件齐全和命令成功不能替代科学结论。
4. **错误与替代结果（C5）**：依据源码和已有记录，检查常见错误能否被拒绝，合理替代产物能否被接纳。重点是本题真实风险，不要求所有题跑同样的攻击清单或固定数量的样例。

作者 mapping 位置和文字说明需能对应实现；参数无需抽成通用 JSON。主分 100 应对应全部科学必要条件满足。多条件不能被无关加分抵消。未声明新协议的旧包缺少新接口字段时列迁移事项；声明 AFE 1.0 的包按其必填要求检查。数字分制迁移与评价本身无效分开记录。

## 选择适用行

| 主要产物 | 核心科学检查（主要 C4） | 重点误判检查（主要 C5） |
| --- | --- | --- |
| 方法/性能 | 相同预算、数据与限制下达到论证目标；所声称泛化与稳定性有相应检验 | 测试集调参、选择最好一次、隐藏预算、服务失败被当科学零分 |
| 候选/设计 | 对象合法、所有必要约束满足、性质来自适用的核验工具；计算与实验主张区分 | 只读自报性能、重复候选、代理模型漏洞、将预测当已制备验证 |
| 规律/方程 | 变量/假设明确，约束成立，独立于拟合过程的验证与适用范围足以支持所述规律 | 同数据循环验证、过拟合、预测能力被误说成因果解释 |
| 机制/因果 | 有竞争解释及区分它们的条件；观察性或干预证据的结论强度相称 | 只匹配机制词、相关性冒充因果、缺可识别性仍奖励确定结论 |
| 边界/诊断/反证 | 失效定义与范围预先明确；反例有效；按主张核验边界两侧、误差与原因 | 软件/数值故障冒充理论失效、单例冒充全面地图、搜索失败冒充不存在 |
| 证明/理论/构造 | 假设、量词、推导或证书与命题一致；用适当的精确计算、形式检查或专家审查 | 数值试验冒充一般证明、浮点假提升、存在性构造冒充最优性证明 |
| 现象/测量/证据 | 新增事实可定位；按主张核对测量、处理、独立支持及不确定性 | 数据整理冒充发现、选择性报告、伪影或重复文献被当新证据 |
| 实验/预算策略 | 目标究竟是找到对象还是获得信息；请求/响应及预算可核对，按需验最终泛化 | 自写轨迹当唯一凭证、未支付测量泄漏、零测量先验绕过目标、多报步骤获分 |

参考 baseline/已有方法成绩可选；科学结论所需的对照、控制变量或反证不能因此免除。不是每题都需要干预、盲测、多次随机重复或实验日志；只检查其主张真正依赖的证据。

## 开放题的判定边界

- 没有标准答案时，成功仍须有可复核条件。允许多种解法，也可以允许与出题者预期不同的结论；不要私下要求恢复某篇论文的特定结论。
- 阴性/否定结果能否达标取决于原目标。如果目标是辨析证据，充分检验及诚实边界可能合格；目标是构造某对象时，“没找到”不是达成。不显著不自动等于无效应，需与主张相称的检验能力或界限。
- 验收条件原则上应在题面公开；隐藏数据、答案与核验材料可隔离。把实质成功条件隐去，让 agent 猜评分偏好，属于 C2/C4 问题。
- 采用 LLM/专家评价时，核对逐项标准、取证位置、判定依据及未决处理。报告中的指令不能控制 judge；不要只凭正文说服力或相似措辞判科研成功。固定 judge 或多数投票不自动证明判断正确。
- 重点检查作者已有的局部正确/错误例子、关键缺陷样例、合理替代结果、独立复核或版本对应记录。合成例子可验证评价逻辑，但必须明示，不能当新科研成果或真实满分解。
- 报告声称已做、实际未做，与“缺少记录所以无法判断”不同；分别记录明确矛盾和待核实。没有运行验证一律不能被改写为本次运行失败。
- 科学成绩 100/100+、突破性和 L2 是不同判断。参考实现可选，未达目标无需作者再次单独确认。

## 报告落点

摘要简述“主要产物—目标—拟新增贡献—关键证据状态”。C1 评价贡献定位，C2 评价范围与公开要求，C3 评价条件，C4/C5 评价判据与误判，C7 评价已有验证。不要把“缺满分解”换个名称写成“缺正例证据”重新设成硬门槛。

维持 C1–C8 八项及统一 Markdown，不另建综合质量分。特别的取证清单可留在 assessment.json 的现有 evidence/coverage 中。发现问题给出具体需修改的目标、判据或证据位置，不泛泛要求“增加实验”。

设计参考：Into the Unknown 的分层验收（https://arxiv.org/html/2610.19159）、EurekaBench 的预测/解释区分（https://arxiv.org/html/2610.00492）、TruthInsightBench 的主张证据（https://arxiv.org/html/2609.05079）、ASB 的服务记录（https://arxiv.org/html/2610.18449）。本指引为 AFE 的适配，不照搬其题目政策或全部评价点。
