# 研究目标与评价说明（填写参考）

用于 AFE L1“限定目标的科研挑战”。只需说明适用内容，可以合并到现有题文、评分说明或补充材料，不强制新增同名文件，不重复网页团队与授权信息。初次提议可列缺失项；正式评测前再落实评价实现与证据。

## 研究目标与贡献

- 研究问题：要解决哪一个限定问题？
- 已有基础：相关研究、方法或数据是什么，核对到什么日期？
- 新增贡献：完成本题后，将新增什么知识、方法、对象或证据？
- 目标边界：固定哪些条件、允许探索哪些方法、预算与可用信息是什么？

## 产物与验证

- 需要交付的核心产物：例如候选对象、模型、机制证据、边界图或证明。
- 满分的科学含义：什么结果足以说明目标达成？优化题请给出专家论证的固定目标及依据；不要求已有满分解。
- 必要条件：哪些条件必须满足，不能用其他加分项补偿？允许哪些等价解法或非预期但有效的结论？
- 取证与判断：各项依据什么数据、代码、证明或记录，采用何种检查？需要专家复核时由谁承担、怎样反馈？
- 证据边界：哪些结论仅在计算/仿真/现有数据内成立；哪些还需进一步实验？

可按需要用下面的小表，也可直接写文字：

| 待核验主张 | 证据或材料位置 | 满足条件与未决情况 |
| --- | --- | --- |
| 用本题的科学主张填写 | 指向实际材料或约定产物 | 明确判定方法，避免只写“合理”“有创新” |

## 评分实现

- 映射实现位置：评分文件路径及函数/入口。
- 简短描述：说明原始结果怎样映射到 0–100；函数参数直接保存在实现中，无需重复建立 JSON 端点表。
- 参考方法及成绩：可选；没有则无需补一份满分解。
- 如适用，说明如何判断超过目标：数值主分仍封顶 100；在 metadata.afe.supports_over_target 声明能力，按需在结果中输出 target_exceeded；该标记不自动改变 Level。

## 已有验证与待补事项

列出已有记录及其对应版本、已发现的局限和需要的技术协助。针对本题最可能的误判，说明如何排除，例如：无证据但结论写得很好、对象无效却声称性能很好、预算超限、把相关性说成因果。可以使用局部例子或明确标注的合成例子核验评分逻辑，不必先解决整个开放问题；这些例子不是新的科学成果。
