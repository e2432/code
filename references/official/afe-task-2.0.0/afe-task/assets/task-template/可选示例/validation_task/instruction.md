# 合成预算查询示例

这是 validation 接口演示，不代表真实科研挑战。供题时替换目标、候选和计算过程，并说明新增科学贡献。

有 c1、c2、c3、c4、c5 五个合成候选。请在最多查询 3 个不同候选的预算内选出一个值不低于 0.8 的候选；值越高越好，可继续优化。

## 中途验证

环境提供 Python 3.11。使用：

```sh
python3 /work/tools/validate.py --candidate-id c1
```

成功时返回 `query_id`、`candidate_id`、`value`、`remaining`。每次有效的新候选查询消耗 1 次；重复查询返回同一记录，不额外扣费；不存在的 ID、错误格式和预算不足请求不扣费。服务会保留记录，修改本地反馈不能改变正式查询历史。

最终将所选的查询 ID 写入 `/work/output/submission.json`：

```json
{"query_id":"q1"}
```

只能选择本次服务实际返回的查询。评分器从服务记录中读取对应值，在预算内达到目标才算完成。解题时限 300 秒、1 CPU、1 GB 内存；可以访问验证服务，无需其他外部服务。
