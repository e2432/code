# 合成预测示例

这是文件交接和评分接口的演示，不是真实科研问题。供题时请替换本说明、数据和评价逻辑，说明你的研究缺口及达成后的新贡献。

## 目标与输入

读取 `/work/input/samples.csv`，为每个 sample_id 提交一个预测值。示例验收指标为平均绝对误差：不高于 6 即达标，越低越好，可以继续优化。所有值均为无量纲合成数值。

## 环境与限制

环境提供 Python 3.11 标准库。输入中的 feature 是允许使用的特征；没有专用中途验证工具。解题资源为 1 CPU、1 GB 内存，时限 300 秒，运行时不联网。

## 最终交付

将结果写入 `/work/output/predictions.csv`，编码 UTF-8，第一行固定为 `sample_id,prediction`。每个输入 ID 恰好一行，prediction 为有限数值，不多交或漏交 ID。

格式示例（数字只是格式占位，不是参考结果）：

```csv
sample_id,prediction
s1,1.0
s2,2.0
s3,3.0
```

评分器根据独立保存的目标值计算误差。交付文件缺失或格式不符时按无效提交处理。
