# AFE 任务包构建与审核

版本 2.0.0，沿用 AFE 协议 1.0。它把原 afe-harbor-review 的审核功能和新的构建指导放在一个 skill 内，随包提供共建指南、完整任务模板与检查工具。

## 怎样使用

解压后保留完整 afe-task/ 文件夹，放入 agent 的技能目录，或直接让 agent 阅读其中 SKILL.md；不用安装旧 afe-harbor-review。已有旧版时先保留备份，再替换发现入口，避免同时加载两套说明。

构建或修改任务：

```text
请阅读 /path/to/afe-task/SKILL.md，使用构建模式，
根据我提供的科研问题和材料，在 /path/to/output 中制作 AFE 任务包并自查。
科学目标、满分条件或必要材料不明确的地方请向我确认。
```

只审核已有任务：

```text
请阅读 /path/to/afe-task/SKILL.md，使用审核模式，
静态审核 /path/to/task_package 及我提供的补充材料，
报告写到 /path/to/review_output，保持任务包只读。
```

已安装并支持技能发现的 agent 可直接使用 `$afe-task`。无需阅读代码；根据 agent 的问题补充科研决定和材料即可。

## 两种模式做什么

构建模式整理科研目标、输入、产物和验收条件，选择模板并生成或修改任务文件，完成结构与内容自查。关键科学条件不明时会询问作者；材料不完整也可形成注明缺口的草稿，不会编造专家阈值或创新性证据。

审核模式只读任务和已有证据，检查七组格式问题与八项内容质量：科学价值、任务自洽、数据环境、评价有效性、评分健壮性、答案隔离、验证证据、来源与交付边界。每项为 0–3 档或待核实，不合成总分；输出固定格式的 review.md，列明依据和整改建议。构建后的报告标注自查，不冒充独立审核。

参考方法和成绩都可选；没有参考解、未达目标或未满分本身不扣档。题文不用公开分数映射。已有研究材料支持创新性判断，但本工具不凭静态阅读保证全领域无人做到过。

结构检查需要 Python 3.11+，或 Python 3.8–3.10 与 tomli。审核不运行题包，不需要 Harbor、Docker 或飞书登录。构建默认静态自查；实际运行按用户授权和可用环境开展，如实区分未运行、合成测试与真实联调。skill 不自动提交、发布或开展科研实验。

随包模板在 assets/task-template/。普通共建者可阅读其中共建指南；agent 根据 SKILL.md 按需读取其余资源。主分仍为 0–100，超目标仍封顶，审核规则与构建规则共用一套接口。
