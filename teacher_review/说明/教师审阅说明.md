# AFE L1 任务包教师审阅说明

## 1. 这份材料要审阅什么

这是一份面向科学具身智能的 AFE L1 任务包初稿，任务名称为“连续稀释与定量移液”。

Agent 在一个模拟实验室环境中，根据给定的实验协议完成四级连续稀释，处理一次预设的临时移液失败，记录有限的体积测量误差，并提交实验质量报告。

任务包当前版本为 `0.5.1`。它用于审阅任务目标、实验流程和评价设计，当前不依赖真实机器人或湿实验设备。

## 2. 科学目标

从 1000 µM 库存液制备四个目标浓度：

- T1，500 µM
- T2，250 µM
- T3，125 µM
- T4，62.5 µM

流程采用连续 1:2 稀释。每一级加入 500 µL 前一级溶液和 500 µL 稀释液，混匀后向下一级转移 500 µL。流程结束时，T1、T2、T3 各保留 500 µL，T4 保留 1000 µL。

任务的科学结果是目标浓度、终态体积和可审计的实验质量记录。任务不要求发现新规律、提出新方法或形成科学突破。

## 3. 为什么定位为 L1

该任务要求 Agent 完成一个受约束、可复现、可独立验收的科学流程。它包含：

- 连续稀释关系的理解
- 液体体积和溶质守恒
- 样品来源和操作顺序控制
- 混匀和吸头污染控制
- 移液失败后的重试
- 测量误差下的质量记录

目标是完成既定实验流程，目标本身不涉及已有研究未实现的科学贡献，因此定位为 L1。

## 3.1 L1 与仿真环境的关系

AFE 指南对 L1 的要求集中在科研目标、流程挑战、资源约束和可验收标准。L1 等级本身不强制使用 MuJoCo、AutoBio、真实机械臂或湿实验设备。

本任务采用仿真环境是工程实现选择。仿真可以提供可重复的实验条件、可控的故障事件、可记录的观测和自动评分。仿真环境需要在任务包中明确说明场景、工具、输入、输出、资源和验证方式。

当前 v0.5 已完成抽象仿真器中的流程、移液误差、测量误差、故障、对照、校准、暂停和评分逻辑。AutoBio/MuJoCo 场景、机械臂运动学和视觉观测属于后续接入阶段。

## 4. Agent 的实际工作流程

1. 读取 `/work/input/protocol.json`。
2. 根据协议规划移液和混匀动作。
3. 使用反馈工具逐步执行动作。
4. 遇到临时移液失败时保留失败事件，并提交带 `retry_of` 的重试动作。
5. 在流程结束后执行 `measure` 动作，获得带有限误差的体积测量值。
6. 提交 `/work/output/submission.json`。

反馈工具的调用形式如下：

```bash
python3 /work/tools/feedback.py \
  --protocol /work/input/protocol.json \
  --state /work/output/feedback_state.json \
  --action /work/output/next_action.json
```

## 5. Agent 需要提交什么

`submission.json` 包含两部分。

### 动作记录

`actions` 按实际执行顺序记录：

- `observe`、`move`，记录视觉观察和机械臂移动
- `transfer`，定量转移
- `mix`，混匀
- `measure`，测量终态体积

失败动作必须保留在记录中。重试动作使用 `retry_of` 指向失败动作的 `action_id`。

### 实验质量报告

`report.samples` 需要为 T1–T4 分别提交：

- 测量体积
- 体积误差
- 估计浓度
- 浓度误差
- 质量标记

`report.events` 需要记录失败动作和失败原因。`report.quality_flags` 需要说明是否考虑测量不确定性、是否完成重试以及是否避免跨源吸头复用。

## 6. 评分方式

独立评分器会重放动作，并检查：

- 终态体积误差不超过 5 µL
- 目标浓度误差不超过 1%
- 失败动作没有改变容器状态
- 重试动作引用了正确的失败动作
- 液体来源和体积满足协议
- 混匀发生在向下一级转移之前
- 吸头没有跨源复用
- 质量报告与重放得到的测量值一致

标准动作测试结果为：

```text
status = evaluated
score = 100
reward = 1
```

## 7. 当前模拟设定

当前版本使用确定性的模拟误差和失败事件，便于复现和审计：

- 体积测量误差按协议中的固定模式产生
- `t2_sample_attempt1` 触发一次临时移液失败
- 失败动作不改变容器状态
- 带正确 `retry_of` 的重试动作可以继续流程
- 跨源吸头复用会被记录为污染风险

这些设定用于评价 Agent 的流程执行和反馈处理能力，不能直接等同于真实仪器的误差模型。

## 8. 请老师重点确认的事项

1. 连续稀释流程和终态体积设定是否符合预期实验习惯。
2. 500 µL 的转移体积和当前移液器范围是否合理。
3. 1% 浓度误差和 5 µL 体积误差是否适合作为验收阈值。
4. 当前固定测量误差模式是否需要改成随机但可复现的误差模型。
5. 临时移液失败和吸头污染的反馈方式是否足够接近目标实验流程。
6. 是否需要增加重复测量、空白对照、校准步骤或异常液体量场景。
7. 是否需要增加多个随机化实验实例，以检验 Agent 的泛化能力。

## 固定库存液、空白样和浓度主指标

库存液和 750 µM 标准样采用固定参考浓度。空白样只用于检查背景信号和携带污染，不参与目标浓度主指标计算。

目标管的浓度误差按三次体积测量的平均值计算。仿真器根据移液动作重建溶质量 `S_reconstructed`，将三次测量平均体积记为 `V_measured`，然后计算：

```text
C_estimated = S_reconstructed / V_measured
concentration_error_fraction = |C_estimated - C_target| / C_target
```

四个目标管的真实浓度误差是主指标，体积误差是辅助指标但有 5 µL 硬门；Agent 报告的浓度估计、测量误差和总体标准差作为独立诊断。最终分数先检查完成门：科学门失败时最高 50 分，只有记录门失败时最高 80 分，全部必要条件满足才得 100 分。标准样和空白样在 v0.5.1 只作体积质控，因为当前没有独立浓度 assay；安全处理 `low_stock` 场景按协议记录为预期暂停。三次测量的标准差用于记录重复性，实际移液误差和吸头携带体积会进入状态重建。

## AutoBio 对接边界

AutoBio 原生公开代码支持 MuJoCo 容器液体积、液面几何、吸头与液面的相对位置、机械臂控制、相机观测、轨迹记录和多 episode 评测。它没有规定浓度测定、标准样或空白对照。本任务暂时只把标准样和空白样作为体积质控；独立浓度 assay 需要后续增加 `assay` 观测通道。接入 AutoBio 时，机械臂和液面执行结果由 AutoBio 层提供，化学准确度和计量诊断由 AFE 评分层完成。
