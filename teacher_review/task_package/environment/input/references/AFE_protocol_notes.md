# Agent 运行参考：协议和科学计算

## 单位

- µL 表示液体体积，描述移液器取放多少液体。
- µM 表示浓度，描述单位体积中的溶质量。

连续稀释使用 500 µL 样品和 500 µL 稀释液。目标浓度依次为 500、250、125、62.5 µM。所有转移必须使用 P1000。

## 固定参考液

库存液固定为 1000 µM。标准样固定为 750 µM。空白样浓度为 0 µM，只用于背景和携带污染检查。

## 浓度误差

评分器根据动作重建溶质量 `S_reconstructed`，并使用三次体积测量平均值 `V_measured`：

```text
C_estimated = S_reconstructed / V_measured
concentration_error_fraction = |C_estimated - C_target| / C_target
```

浓度误差是主指标。体积误差使用同一平均体积计算，阈值为 5 µL，是辅助指标。

## 测量误差

测量误差采用固定 seed 的正态分布，均值为 0 µL、标准差为 1 µL，并在 ±3 µL 截断。同一实例和 seed 产生同一组误差。

## 空白和标准样

目标管、空白样和标准样均测量三次。空白样不参与目标浓度主指标，标准样用于检查已知浓度参考的测量和计算流程。
